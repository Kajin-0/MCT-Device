## Scope

## Publication rule

The bibliography in the Round-53 booklet candidate is assembled from controlled repository records only. For every entry:

- primary-source metadata already controlled in `docs/SOURCE_LEDGER.md` or a procedure/source addendum are retained;
- DOI/patent/report identifiers are included when controlled;
- incomplete source metadata remain explicitly incomplete;
- no missing page, title, journal, year, author, or DOI field is filled from memory or generic search resemblance;
- secondary sources remain mapping/context sources and do not displace primary evidence for process-critical setpoints.

# Source-ledger addendum — Round 60 deep research

**Date:** 2026-08-17 America/New_York

## Purpose

Record new primary and official source families used to deepen the apparatus/operator layer of the exhaustive empirical protocol. These sources do not alter the evidence class of older RP-01 facts and do not convert current vendor implementation guidance into historical identity.

## Evidence rules

- `RP`: direct Smith/RP-01 evidence.
- `SL`: same-lineage evidence.
- `PT`: primary transfer evidence.
- `DER`: derived quantity.
- `SYN`: synthesized empirical starting implementation.
- Optional `SYN-H/M/L` indicates confidence in a synthesized implementation, not higher provenance.

Current manufacturer, NIST, NASA, DOE/PNNL and standards documentation is appropriate for defining a modern implementation or calibration practice. It is **not** evidence that Smith/UWA/Fermionics historically used the current product/tool.

## New load-bearing source families

### Radhakrishnan, Sitharaman & Gupta (2003)

`J. Cryst. Growth 252 (2003) 79–86`, DOI `10.1016/S0022-0248(02)02530-7`.

Use:

- modified horizontal-slider architecture;
- high-purity/high-density graphite;
- `15 × 15 × 1 mm` CdZnTe substrate;
- quartz-tube / stainless-flange / gas-port / push-pull / thermocouple apparatus context;
- 6N Hg/Cd/Te;
- evacuated quartz source synthesis at `700 °C / 8 h`;
- `10 g` source batch, `~4.8 g` run charge, `3 g` HgTe reservoir;
- meltback/wipe-off/Hg-loss-compensation process architecture.

Classification: `PT` relative to RP-01 upstream reconstruction.

### PNNL-37304

DOE/PNNL technical report on quartz ampoule fabrication/sealing practice.

Use only for:

- clean quartz handling;
- practice seals;
- flame sealing and inspection concepts;
- secondary-containment/safety thinking.

Restriction: its reported slight-vacuum irradiation-specimen pressure is a different application and is **not** an HgCdTe source-synthesis vacuum specification.

Classification: official transfer practice.

### NISTIR 6643 — mercury vapor pressure

Use:

- Hg vapor-pressure/temperature thermodynamic and handling basis;

Restriction: does not determine the pressure inside the reacting multicomponent source ampoule by itself.

Classification: official physical-property source.

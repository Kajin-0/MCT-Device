# Integrated manual manuscript

The canonical integrated draft is:

`RP01_HGCDTE_PHOTOCONDUCTOR_PROCESS_MANUAL_DRAFT.md`

This manuscript is the user-facing technical deliverable under development. Detailed `procedures/`, `calculations/`, `travelers/`, and source ledgers are supporting controlled records.

## Governing distinction

The manuscript must not be blocked merely because an unspecified future laboratory has not yet instantiated apparatus-specific calibration values.

Classify remaining quantities as:

- `HISTORICAL/REFERENCE FIXED` — directly sourced or explicitly derived;
- `REFERENCE QUALIFICATION CENTER` — literature-grounded first transfer condition;
- `LOCAL EXECUTION INSTANTIATION REQUIRED` — actual hardware/material dependent and must be measured before irreversible execution;
- `HISTORICAL IDENTITY OPEN` — unrecovered detail that matters only to a literal historical-reproduction claim unless it also prevents defining a local branch.

The final booklet should present one coherent process first; internal repository history and software/provenance infrastructure belong in appendices or supporting records, not the main narrative.
